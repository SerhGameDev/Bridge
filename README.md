# Bridge.Core

Bridge.Core — независимая библиотека для структурированных JSON-документов с блоками, запросами и безопасными ссылками. Проект рассчитан на .NET Standard 2.1 и Unity; публичный API пока находится на этапе проектирования.

См. [русское описание](README.ru.md) и [контракт формата v1](docs/format-v1.md).

> Stage 0 scaffold: the format and API examples are contracts, not implemented behavior. No NuGet or Unity package has been published.
