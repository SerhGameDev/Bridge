# Bridge.Runtime

Ядро зарегистрированных команд и ограниченного чтения Bridge.Core. netstandard2.1, один source для .NET/UPM, без UnityEngine/MCP/автоматического network listener. MIT. Документация и окончательные примеры будут добавлены последовательно в R2–R7; текущий R1 реализует builder/host/lifetime и договоры источников/dispatcher.
