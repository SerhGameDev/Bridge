# Bridge.Core

Bridge.Core — независимая библиотека для структурированных документов в стандартном JSON. Документ содержит именованные блоки с типом, версией схемы и произвольными JSON-данными. Библиотека проектируется для обычных .NET-приложений и Unity без зависимости от `UnityEngine`.

## Цели

- Чтение, проверка и запись файлов `.bridge.json`.
- Доступ к блокам и типизированное преобразование данных в DTO.
- Обычные LINQ-запросы и ограниченная fluent-модель запроса.
- Безопасное разрешение ссылок между документами через внедряемый резолвер.
- Совместимый с AOT путь для явно зарегистрированных DTO-сериализаторов.

Формат и API пока заданы как контракт этапа 0; реализация начнётся на следующих этапах. См. [контракт формата](docs/format-v1.md), [решения по дизайну](docs/design-decisions.md) и [пример документа](samples/contracts/minimal.bridge.json).

Планируемая цель библиотеки — `netstandard2.1`. Проект не включает Bridge.Runtime, MCP, AI-сервисы, Unity-зависимый код или выполнение данных из документов.
