# Ссылки между документами

На этапе 0 зафиксированы правила формата в [format-v1.md](format-v1.md) и архитектура резолвера в [design-decisions.md](design-decisions.md). API `IBridgeDocumentResolver`, in-memory реализация, ограниченная файловая реализация, диагностика ошибок и лимиты будут реализованы и уточнены на этапе 4.

Файловый резолвер рассчитан на стабильный доверенный локальный корень. Он отвергает symbolic links/reparse points, включая корень и его предков; проверяет путь до и после открытия файла. Portable managed API не гарантирует атомарную защиту от злонамеренной конкурентной замены каталогов. Для такого threat model нужен собственный handle-based resolver и защищённый root. Кеш существует только в одной ResolveReference; новый вызов заново загружает внешние файлы. Обход графа ограничен глубиной, числом документов, суммарным UTF-8 размером канонической записи и числом посещённых рёбер.
