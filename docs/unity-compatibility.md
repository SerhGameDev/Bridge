# Unity compatibility

Совместимость на этапе 0 не подтверждена тестовой сборкой. В окружении обнаружены редакторы Unity 6000.6.7f1 и 6000.7.0a2; это версии `6000.6` и `6000.7` по Unity numbering. Проверка импорта UPM, Editor tests и IL2CPP относится к этапу 5. До таких проверок не считать пакет готовым для Unity/IL2CPP.

Планируется один источник кода в `Packages/com.serhgamedev.bridge.core/Runtime`, используемый .NET проектом через linked Compile items. Финальные шаги установки и ограничения будут записаны после реальной проверки.
