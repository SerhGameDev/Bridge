# RFC: ограниченная выборка вложенных данных после v0.2

Статус: проект решения, реализации нет. В v0.2 QuerySpec v2 добавляет только точный массив типов. Вложенная выборка потребует следующей версии QuerySpec (предположительно v3), а не скрытого расширения строгих v1/v2.

Сценарий: data одного scene.layout содержит 10 000 объектов. Приложение должно запросить лишь разрешённые поля ограниченного числа элементов. Предлагается отдельная операция над JSON Pointer, с явным offset/count и списком прямых полей каждого элемента. Код, eval, IQueryable, произвольный JsonPath и сетевой доступ не допускаются.

Перед реализацией нужны лимиты числа прочитанных элементов, глубины, числа проекций и размера результата; JSON Pointer escaping ~0/~1; точные правила индексов массива, отсутствующего поля и null; детерминированный порядок; отказ без частичного результата; тесты отсутствия утечки исключённых полей. Варианты фильтрации должны быть конечным типизированным словарём, не C# выражениями. Пока используйте Data.Items и явный System.Linq в доверенном приложении: такой LINQ не является сериализуемым query spec.
