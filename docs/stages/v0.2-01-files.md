# v0.2 — подэтап 1

Добавлены BridgeFile.Exists/Load/TryLoad/Save/SaveAtomic/TrySaveAtomic, document.ContainsBlock/HasField/Get/Set/TryGet/TryRead и block.HasField. Поля прямые и точные, JSON null присутствует. TryGet возвращает false только при missing; неверный тип выдаёт BridgeException. TryRead возвращает диагностику. Некорректные аргументы — ArgumentException.

Save использует SaveAtomic: сериализация завершается до IO, временный файл в целевой директории, Flush(true), File.Replace для существующего файла либо File.Move для нового. Удаления destination перед переносом нет. Ошибки FILE_NOT_FOUND/FILE_ACCESS/FILE_IO отличаются от JSON/schema; FILE_TEMP_CLEANUP сообщает о невозможной очистке. Атомарность зависит от filesystem; power-loss durability не обещается. Проверка Exists не гарантирует последующее чтение.

Фактические проверки Windows: dotnet build -c Release --no-restore — PASS, 0 warnings/errors; dotnet test -c Release --no-build — PASS 103/103. Покрыты missing/null/type, case/exact keys, nonobjects, неверные аргументы, BOM/UTF-8, исчезнувший файл, corrupt/schema/version, locked/read-only destination, сохранность старого файла и очистка temp. dotnet run --project samples/Bridge.Console.Beginner -c Release — BEGINNER_PASS (speed=2, projection=1). Unix permissions проверяются только где поддерживает ОС; Linux в финальном CI.

Следующий подэтап: явные повторно используемые DTO-конвертеры и изоляция реестров документов. Переход последовательно разрешён пользователем для всех оставшихся подэтапов.
