# v0.2 — подэтап 3

WhereTypes(params string[]) и BridgeQuerySpec.ForTypes реализованы: OR типов, AND с ID, ordinal case-sensitive, дубликаты удаляются, пустой список даёт пустой результат, повторный type-фильтр заменяет предыдущий, builder immutable. Single-type/no-type specs используют прежний queryVersion 1; empty/multi-type — queryVersion 2 с types. Парсер строго принимает обе версии; v1 по-прежнему отвергает types. Ни один query не исполняет код.

BridgeBlock инвалидируется при RemoveBlock; старый handle не оживает после Add с тем же ID. Data/Type/References/Get/Set/Deserialize/HasField/SetReference после удаления дают BLOCK_REMOVED. Id и SchemaVersion остаются историческими метаданными для идентификации ошибки. Ранее полученные BridgeValue snapshots сохраняются. Blocks кэширует отсортированный readonly список, Add/Remove сбрасывают кэш; Set не меняет состав списка. Выданный список — снимок состава, его элементы являются handles, а не неизменяемыми данными.

Проверки: Release build 0 warnings/errors, dotnet test — PASS 108/108. Обновлены beginner sample и Unity Editor/player smoke для multi-type и stale handle; финальная Unity проверка включает их. Вложенная выборка вынесена в docs/query-v2-proposal.md как RFC будущей версии; HasField остаётся точным прямым полем.

Performance smoke в одном .NET процессе: 3 warm-up + 10 repetitions, тот же набор block handles. Legacy replay воспроизводит алгоритм getter v0.1 (Dictionary.Values.OrderBy(...).ToArray + readonly wrapper), cached использует новый getter. Это сравнение алгоритмов доступа, не одновременный запуск двух бинарных версий.

| Блоков | Legacy getter ms/op, B/op | Cached getter ms/op, B/op | Текущий query ms/op, B/op |
| --- | --- | --- | --- |
| 1 000 | 0.0876; 28 300 | <0.0001; 4 | 3.4572; 1 818 228 |
| 10 000 | 2.5006; 280 300 | <0.0001; 4 | 24.0526; 18 213 204 |

4 B/op — амортизированная стоимость Stopwatch самого harness; кэшированный getter объектов не создаёт. Query сохраняет snapshot-копирование JSON; общего ускорения запросов относительно старого бинарника не заявляем. Измерение не SLA. Воспроизведение: dotnet run --project samples/Bridge.Console.Sample -c Release -- --performance. Следующий подэтап: документация/Wiki.
