# v0.2 — подэтап 2

BridgeSerializer.Clone и document.UseSerializers копируют таблицу явных generic-конвертеров. BridgeFile.Load/TryLoad принимают именованный serializers. Для Create/Parse/Load(Stream) используется явно .UseSerializers(registry): это сохраняет бинарные сигнатуры v0.1 и не добавляет двусмысленность Parse(json, null). document.Serializers.Register сохраняется; повторная привязка заменяет локальные регистрации, включая уже выданные handles. Конвертеры не записываются в JSON.

Два документа и исходный реестр имеют независимые таблицы. Делегаты и их targets копируются по ссылке: конвертеры должны быть stateless либо синхронизироваться вызывающим кодом. BridgeDocument и изменяемый BridgeSerializer не thread-safe; регистрация/привязка одновременно с использованием не поддерживается. FormatException/OverflowException/InvalidCastException делегата становятся DTO_CONVERSION с контекстом блока; BridgeException сохраняется, непредвиденные пользовательские programming exceptions не подавляются. Null вместо BridgeValue от writer также диагностируется.

Проверки: dotnet build -c Release --no-restore — PASS (0 warnings/errors), dotnet test -c Release --no-build — PASS 105/105. Verify-Unity.ps1, Unity 6000.6.7f1 EditMode — PASS 11/11. Обновлён WebGL smoke для typed shared registry; его реальная IL2CPP сборка/выполнение проверяется в финальном подэтапе после всех изменений.

Следующий подэтап: WhereTypes, QuerySpec v2, lifecycle блока и измерения allocations/time.
