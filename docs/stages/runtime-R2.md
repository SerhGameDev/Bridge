# Runtime R2 — commands, binder, schemas

Base integration01b15a5606a666d996d4a6ce0a1dc9f1dc4afe10 (R1 PR3, CI42603188441 success). Branch feature/runtime-r2-commands. Мини-план: immutable registry, strict signatures и schemas, typed codecs/registrar, затем binding/discovery tests.

Реализованы BridgeCommand/BridgeRange/BridgeDescription/BridgeAllowNull attributes. AddCommands отражает только явно переданный instance и public tagged methods, не сканирует assemblies; private/unmarked недоступны. Имена ASCII letter + letters/digits/underscore/dot/hyphen, 1..128, ordinal/case-sensitive; коллизии отвергаются. Default permission Admin, None на команде запрещён. Build отвергает generic/ref/out/pointer/static/params/async-void/неподдерживаемые return types. Sync void, Task, Task<T> поддержаны; ValueTask MVP не поддерживает.

JSON Schema subset: object/properties/required/additionalProperties=false, numeric type/range, string enums/descriptions, bounded arrays, nullable anyOf. Unsupported schema keywords не игнорируются. Object DTO требует явного BridgeCodecRegistry.Register<T>(schema,read,write), enums — RegisterEnum<T>(); primitive numeric/string/bool и nullable numeric/bool встроены. Integer binder принимает математически целые 1.0/1e0 без принятия дробей из-за округления. Nullable reference arguments требуют BridgeAllowNull или optional-null; одной C# annotation недостаточно. CancellationToken инъецируется host-ом и не входит в client schema. Extra/missing/type/range отвергаются до handler; output тоже проверяется. Программная ошибка codec не публикуется как произвольный CLR type activation.

Для AOT AddCommand<TArguments,TResult>(name,handler,permission,description) использует статические delegates и явные object codecs. Атрибутный путь требует сохранения отмеченных методов в Unity; actual IL2CPP проверяется в R5. Task<T> распаковывается typed codec-ом, без MakeGenericMethod/динамической генерации/рефлексивного Result getter. Codecs snapshot при UseCodecs/Build; closures state остаётся ответственностью приложения.

Файлы: Runtime CommandAttributes/BridgeSchema/BridgeCodecRegistry/CommandRegistry + host bootstrap, .NET CommandTests, console sample. Public execution/санитизация полного результата будет в R4; сейчас CommandsFor(context) уже фильтрует immutable metadata по permissions. Internal invocation доступен только friend test assembly, не внешнему transport.

Проверки: dotnet build -c Release — 0warnings/errors; dotnet test -c Release — Core109/109 + Runtime20/20 PASS. Тесты sync/async/void, optional, nullable/bool/enum/DTO, cancellation, target exception, forbidden signatures, duplicate, secret/private/unmarked discovery, typed registrar, extra/invalid/range/fraction/overflow/schema parity. Console CATALOG_PASS: math.add. Hosted CI и интеграция фиксируются в PR перед R3.
