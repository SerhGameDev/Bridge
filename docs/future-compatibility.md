# Будущая совместимость

bridgeVersion управляет форматом документа. Неизвестные версии отклоняются без автоматических миграций. schemaVersion принадлежит type блока, предметную валидацию выполняет приложение. Неизвестные поля документа/блоков/refs сохраняются.

BridgeQuerySpec queryVersion 1 допускает известные операции. Будущие изменения смысла потребуют явной версии. Core не реализует Runtime/MCP/AI, исполнение команд или авторизацию; будущий слой сможет использовать спецификации после своей проверки прав и лимитов.

IBridgeDocumentResolver позволяет подключать новые источники. Встроенные резолверы синхронные, без сети. Async/Addressables adapters могут жить в приложении или отдельном слое. ID не превращаются автоматически в URI или имена CLR-типов.

0.1.0 — первый локальный кандидат, до публикации API возможны явно описанные breaking changes. Текстовое оформление JSON не является контрактом; точные ID/keys, семантика JSON, порядок массивов, диагностические коды и запрет исполнения данных — являются.
