# Contributing

Изменения выполняются по этапам и небольшими коммитами Conventional Commits. До начала реализации сверяйтесь с `docs/format-v1.md` и `docs/design-decisions.md`. Не добавляйте UnityEngine в Bridge.Core и не исполняйте код или выражения из входных JSON-документов.

Перед PR должны быть выполнены проверки, перечисленные для соответствующего этапа. Unity и IL2CPP результаты указываются только если они действительно запущены.
